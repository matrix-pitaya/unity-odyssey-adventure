# Odyssey Adventure

Unity 3D platform adventure game project.

## Requirements

- Unity `2022.3.55f1c1`
- Packages are restored from `Packages/manifest.json`

## Project layout

- `Assets/` — game scenes, scripts, prefabs, and project resources
- `Packages/` — Unity package manifest and lock file
- `ProjectSettings/` — Unity editor and project settings

Generated folders such as `Library/`, `Temp/`, `Logs/`, and `UserSettings/` are intentionally excluded from version control.
